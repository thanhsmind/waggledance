## Deviations

- **ott-1** — Made maybe_dispatch take kind as a &str constant instead of a TransitionKind enum — CI runs clippy -D warnings, so an enum with the three not-yet-constructed D4b/c/d variants would fail the build on dead_code until ott-2/3/4 land — hit an unforeseen obstacle
- **ott-1** — Added reaper_verdicts_armed/trigger_dry_run_armed flags so reconcile restarts a running reaper/trigger whose construction-time wiring no longer matches config, instead of the plain (true, Some(existing)) no-op — without it, arming the trigger while the reaper was already sweeping would silently never deliver a single D4a verdict — something else had to be fixed first
- **ott-1** — Read the trigger's verdict sender off a TerminalBackground slot inside reconcile_reaper_with_timings rather than adding a parameter to it — keeps every existing caller and the reaper's own two main.rs tests on their current signature with None behaviour byte-for-byte — found a better route
- **ott-4** — Filtered the reader on event == "record" as well as on kind — the real generated bytes showed interventions.jsonl is an append-only EVENT log (a mark-delivered stamp appends a line with no kind field at all), which CLI help text did not say — the plan was wrong about a fact
- **ott-4** — The first read of a project's mailbox primes the cursor and dispatches nothing, rather than treating first sight as a transition the way scan_blocked does — a herdr snapshot is current state but a mailbox is history, so priming is what keeps a daemon restart from waking a tick per historic row — found a better route
