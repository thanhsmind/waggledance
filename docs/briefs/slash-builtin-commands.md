**Là gì:** Trước đây gõ dấu gạch chéo trong ô trả lời chỉ gợi ý các lệnh và kỹ năng của dự án, thiếu các lệnh sẵn của agent như /model, /usage, /compact. Từ 31/8, ô đang chạy Claude Code gợi ý thêm các lệnh sẵn của Claude Code; ô dòng lệnh thường không gợi ý lệnh nào loại này.

**Vì sao:** Anh phải nhớ tên lệnh sẵn và gõ tay, nhất là trên điện thoại.

**Nguồn gốc:** Anh yêu cầu ngày 31/8: "command / còn thiếu các command có sẵn của agent"; làm và gộp cùng ngày.

**Chi phí và rủi ro:** Nhỏ, đã xong. Danh sách lấy từ chính bản Claude Code đã cài lúc đó, khoảng một trăm lệnh, không viết theo trí nhớ. Khi Claude Code thêm lệnh mới, danh sách cần được làm mới. Hiện chỉ Claude Code có danh sách; lệnh dự án trùng tên vẫn được ưu tiên.

**Anh cần làm:** (a) Mở một ô đang chạy Claude Code, gõ dấu gạch chéo vào ô trả lời (b) Đóng mà không thử. **Đề xuất:** (a) — một phút là thấy.

**Chuẩn xong:**
- Ô chạy Claude Code gợi ý /model và /usage
- Ô dòng lệnh thường không gợi ý lệnh sẵn của agent
